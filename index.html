How to use it
  1. Pick the track. The setup jumps to a preset for that track. Put the same values on the car in the game.
  2. Run a practice stint, then tap what the driver said for each of the five areas.
  3. Press Find setup. The run is saved and the sliders move to the next setup to try.
  4. Repeat until every area is Optimal. Areas the driver hasn't rated yet can be left blank.

The blue band on each feedback bar is where that driver's ideal can still be. The marker is where the current setup sits. Each run shrinks the band.
